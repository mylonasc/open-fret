# Runtime dependencies (loaded externally, not bundled here)

- AlphaTab 1.3.0 (notation, synthesizer, audio transport, fonts, soundfont):
  https://github.com/CoderLine/alphaTab/tree/v1.3.0
- WaveRoll 0.4.0 (piano-roll rendering):
  https://github.com/crescent-stdio/wave-roll (MIT)
  - PixiJS 8 (renderer): https://github.com/pixijs/pixijs (MIT)
  - Tone.js 15 (bundled audio engine): https://github.com/Tonejs/Tone.js (MIT)
  - @tonejs/midi (MIDI parsing): https://github.com/Tonejs/Midi (MIT)
  - d3-scale (time/pitch scales): https://github.com/d3/d3-scale (ISC)

Each external component and its audio assets remain subject to its own terms.

# Vendored blobs for offline notebook embedding (ui/tab_data_viewer/vendor/)

Generated by `scripts/vendor_viewer_js.py`; same pinned bytes as the CDN URLs
above. `open_fret.viewer.to_html(..., inline_deps=True)` inlines them so
notebook viewers need no network at all.

- `alphaTab.min.js` (MPL-2.0, (c) CoderLine):
  https://github.com/CoderLine/alphaTab/tree/v1.3.0 — MPL Exhibit A notice
  retained in the file header and in `vendor/SOURCES.md`.
- `wave-roll.umd.js` (MIT, crescent-stdio): pinned UMD build.
- `sonivox.sf2` (Apache-2.0, (c) 2004-2006 Sonic Network Inc., via the Android
  Open Source Project SONiVOX EAS presets): pinned soundfont; its LICENSE
  statement is reproduced in `vendor/SOURCES.md`.
